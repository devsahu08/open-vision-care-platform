Why we exist
To provide affordable eyeglasses to needy people around the world — beginning with underfunded schools and elderly communities.

Every initiative that changes lives starts with a noble idea of giving back. iCare Brighter Future Foundation is a student-led nonprofit bringing eyeglasses and vision care to underfunded schools and elderly communities worldwide — starting in India, and beyond. Many children with undiagnosed vision problems silently fall behind in school, mislabelled as inattentive when they simply can't see. For elderly communities, uncorrected vision means losing the independence to read, work, or live fully. A single pair of glasses can change that — this platform exists to help any nonprofit deliver it.

Open-source platform

Bring this to your nonprofit.

This is the same patient registration, eye exam, campaign, and inventory system we use to run our own camps — released so other organizations doing this work don't have to build it from scratch. No cost, no lock-in.

iCareBrighterFuture-api Backend · Python / Flask iCareBrighterFuture-Application Frontend · HTML / JS iCareBrighterFuture-Database Schema · PostgreSQL
01

Get the code

Clone all three repositories above into their own folders.

git clone https://github.com/devsahu08/iCareBrighterFuture-api
git clone https://github.com/devsahu08/iCareBrighterFuture-Application
git clone https://github.com/devsahu08/iCareBrighterFuture-Database
02

Set up the database

Create an empty PostgreSQL database, then run the schema and procedure scripts in order.

psql -d your_org_eyecare -f PatientRegistration/patient_registration_schema.sql
psql -d your_org_eyecare -f PatientRegistration/patient_registration_procedures.sql
psql -d your_org_eyecare -f EyeExam/eye_exam.sql
psql -d your_org_eyecare -f Inventory/inventory_procedures.sql
03

Configure and run the API

Copy .env.example to .env and fill in your own database and secret key values — never commit this file.

DB_HOST=your-db-host
DB_PASSWORD=your-own-strong-password
FLASK_SECRET_KEY=generate-a-long-random-string

pip install -r requirements.txt
python src/api/app.py
04

Point the frontend at your API

Update the API base URL in the frontend config, then host the src folder on any web server.

// js/app-config-v2.js
const API_BASE = "https://your-org-domain.org/api";
05

Create your first admin account

The schema ships with no user accounts. Insert one Coordinator-role user directly into the database with a bcrypt-hashed password — never store it as plain text. From there, log in and create the rest of your staff accounts through the app itself.
